# 🎲 Téléportation aléatoire

La téléportation aléatoire te permet d'être téléporté dans une zone totalement unique et aléatoire dans le monde de ton choix. Cela te permet de découvrir des nouvelles zones inexplorées.

## <mark style="color:yellow;">La fenêtre de téléportation</mark> <a href="#fenetre" id="fenetre"></a>

La commande <mark style="color:yellow;">`/rtp`</mark> ouvre une fenêtre, en deux parties.

### <mark style="color:yellow;">Mes points</mark> <a href="#points" id="points"></a>

Le serveur retient ton dernier point d'arrivée <mark style="color:red;">dans chaque monde</mark>. Depuis la fenêtre, tu peux y retourner à tout moment, <mark style="color:red;">même pendant le délai</mark> avant une nouvelle position.

Ce point est gardé sans limite de temps, jusqu'à ta prochaine téléportation aléatoire dans le même monde.

### <mark style="color:yellow;">Nouvelle position</mark> <a href="#nouvelle-position" id="nouvelle-position"></a>

Choisis le monde dans lequel partir, puis demande une nouvelle position au hasard. Pendant le délai, la fenêtre t'indique le temps restant.

{% hint style="warning" %}
Une nouvelle position <mark style="color:red;">remplace</mark> ton point dans ce monde. Si tu n'y as pas posé de home, tu ne pourras plus y revenir : la fenêtre te demande donc de confirmer avant de partir.
{% endhint %}

## <mark style="color:yellow;">Les mondes</mark> <a href="#types" id="types"></a>

Chaque monde possède son propre délai pour l'obtention d'une nouvelle position. Dans les trois mondes, la distribution va de 0 à 3 500 000 blocs.

### <mark style="color:yellow;">Overworld</mark> <a href="#overworld" id="overworld"></a>

Sois téléporté aléatoirement dans l'Overworld du [monde survie](monde-survie.md).

Le délai pour l'obtention d'une nouvelle position aléatoire est de 1 heure. Pour les grades <mark style="color:red;">Voyageur</mark> et <mark style="color:red;">Novice</mark>, il est réduit à <mark style="color:red;">10 minutes</mark>.

### <mark style="color:yellow;">Nether</mark> <a href="#nether" id="nether"></a>

Sois téléporté aléatoirement dans le Nether du monde survie.

Le délai pour l'obtention d'une nouvelle position aléatoire est de 30 minutes.

### <mark style="color:yellow;">End</mark> <a href="#ender" id="ender"></a>

Sois téléporté aléatoirement dans l'[Ender](ender.md) du monde survie.

Le délai pour l'obtention d'une nouvelle position aléatoire est de 15 minutes.
